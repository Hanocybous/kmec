# KMEC 2026 · Kalamari Model European Conference

Website for the 20th Kalamari Model European Conference (20–22 November 2026), a student simulation of the European Parliament for Gymnasium and Lyceum students.

Static site (HTML/CSS/JS, no build step), English and Greek. Hosted on GitHub Pages.

- `index.html` – page content (English text lives here)
- `assets/main.js` – Greek translations, past sessions, videos, gallery list
- `assets/styles.css` – design
- `assets/img/` – photos from past sessions (source: kalamari.gr)
